# 🚑 ফার্স্ট এইড ও জরুরি গাইড

ইন্টারনেট ছাড়াই চলে — বাংলায় প্রাথমিক চিকিৎসা, সিপিআর ছন্দ-গাইড ও জরুরি নম্বর। ফোনে ইনস্টল করা যায় (PWA)।

**লাইভ লিংক (Pages চালু করলে):** `https://sultanbdstore.github.io/first-aid-bd/`

## কী কী আছে
- **৪৭টি বিষয়** (নতুন: মাছের কাঁটা, তীব্র পেটব্যথা, কানে/নাকে কিছু ঢোকা, নবজাতকের বিপদ-চিহ্ন, প্রচণ্ড ঠান্ডা, প্যানিক অ্যাটাক, অঙ্গ কেটে যাওয়া, মেরুদণ্ডে আঘাত), প্রতিটিতে: কখন ৯৯৯/হাসপাতাল → ধাপে ধাপে কী করবেন → যা করবেন না → জেনে রাখুন; বোতাম চাপলে বাংলায় পড়ে শোনায়।
  - 🆘 জীবন রক্ষা: সিপিআর, গলায় আটকানো (বড়/শিশু), প্রচুর রক্তপাত, অজ্ঞান (রিকভারি পজিশন), হার্ট অ্যাটাক, স্ট্রোক (BE-FAST), মারাত্মক অ্যালার্জি, খিঁচুনি, পানিতে ডোবা, বিদ্যুৎস্পৃষ্ট, হাঁপানি
  - 🩹 আঘাত: পোড়া, হাড় ভাঙা/মচকানো, মাথায় আঘাত, নাকের রক্ত, কাটা-ছড়া, চোখ, দাঁত, সড়ক দুর্ঘটনা, শিশু ব্যাটারি/চুম্বক গিলেছে
  - 🐍 কামড়, বিষ ও গরম: সাপ, কুকুর-বিড়াল (জলাতঙ্ক), বিষ/কীটনাশক, গ্যাস লিক, হিটস্ট্রোক, পোকার হুল
  - 🤒 অসুস্থতা: ডায়রিয়া-ওআরএস, জ্বর, ডেঙ্গু, মাথা ঘুরে পড়া, সুগার কমে যাওয়া, গর্ভাবস্থার বিপদ-চিহ্ন
  - 🌪️ দুর্যোগ: আগুন, ভূমিকম্প, বজ্রপাত, ঘূর্ণিঝড়-বন্যা
  - 💛 মানসিক ও নিরাপত্তা: আত্মহত্যার ঝুঁকিতে থাকা কাউকে সাহায্য, সহিংসতা/নির্যাতন

## GitHub Pages-এ চালু করার ধাপ
1. নতুন রিপো বানান (নাম `first-aid-bd`, Public)।
2. এই ফোল্ডারের **সব ফাইল** (লুকানো `.github` ও `.nojekyll` সহ) রিপোর রুটে আপলোড করুন।
3. **Settings → Pages → Source: GitHub Actions** বেছে নিন (বা Branch: main / root)।
4. কিছুক্ষণ পর `https://<ইউজারনেম>.github.io/first-aid-bd/` খুলবে।
5. ফোনের Chrome-এ খুলে মেনু → **Install app / Add to Home screen**।

## ⚠️ সীমাবদ্ধতা (সৎভাবে)
- এটি সাধারণ প্রাথমিক চিকিৎসার তথ্য — **ডাক্তার, হাতে-কলমে প্রশিক্ষণ বা ৯৯৯-এর বিকল্প নয়**।
- লেখাগুলো আন্তর্জাতিক সাধারণ নির্দেশিকার নীতি (WHO, রেড ক্রস/রেড ক্রিসেন্ট, রিসাসিটেশন কাউন্সিল ধারা) অনুসরণে **নিজের ভাষায়** লেখা; **চিকিৎসক দ্বারা পর্যালোচিত নয়**। অন্যকে ছড়ানোর আগে একজন চিকিৎসককে দেখিয়ে নিন।
- শিশুর ওষুধের মাত্রা ইচ্ছে করে দেওয়া হয়নি — প্যাকেটের লেবেল/ডাক্তার/ফার্মাসিস্ট দেখুন।
- জরুরি নম্বর ২০২৬-১১-১৭ তারিখে প্রকাশিত তথ্য (দৈনিক স্টার, টিবিএস নিউজ ইত্যাদি) থেকে; ফায়ার সার্ভিসের ১০২ নতুন নম্বর, ১৬১৬৩ বন্ধ হয়ে থাকতে পারে। নম্বর বদলাতে পারে — যাচাই করুন।
- সাপের অ্যান্টিভেনম/জলাতঙ্ক টিকা সব হাসপাতালে নাও থাকতে পারে — ১৬২৬৩-এ জেনে নিন।
- "পড়ে শোনানো" ফোনের বাংলা ভয়েসের ওপর নির্ভর করে। সিপিআরের ছন্দ ও কম্পন ফোনভেদে আলাদা হতে পারে।
- আসল ফোনে পরীক্ষা করা হয়নি; ডেস্কটপ ব্রাউজারে সব পাতা ও অফলাইন চালিয়ে দেখা হয়েছে।
